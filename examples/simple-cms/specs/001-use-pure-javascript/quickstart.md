# Quickstart: Eshop CMS

## Prerequisites
- Modern web browser (Chrome, Firefox, Safari)
- Backend API running at http://localhost:3000

## Setup
1. Clone the repository
2. Open `index.html` in a web browser
3. Ensure backend API is accessible

## Usage
1. Navigate using the sidebar menu
2. Select an entity (Users, Products, Orders, Shops)
3. Use the list view to browse items
4. Click "Create" to add new items
5. Click "Edit" to modify existing items
6. Click "Delete" to remove items

## Development
- Edit HTML in `index.html`
- Edit CSS in `styles.css`
- Edit JS in `app.js`
- Use UIKit classes for styling

## API Integration
- The CMS fetches data from the backend API
- Ensure CORS is configured if running locally
