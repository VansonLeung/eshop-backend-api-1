# Package API Contract

This directory contains the public API contracts for the `sequelize-rest-framework` package.

## Contract: Package Exports

**Package Name**: `sequelize-rest-framework`  
**Version**: 0.1.0  
**Type**: ESM Module

## Contract: REST Endpoints Generated by GenericCRUD

When a model is registered with `GenericCRUD.initialize()`, the following endpoints are automatically created:

### POST /api/{CollectionName}
Create a new entity.

**Request**:
```json
{
  "field1": "value1",
  "field2": "value2"
}
```

**Response** (201 Created):
```json
{
  "success": true,
  "status": 201,
  "data": {
    "id": "uuid",
    "field1": "value1",
    "field2": "value2",
    "createdAt": "2025-10-12T00:00:00.000Z",
    "updatedAt": "2025-10-12T00:00:00.000Z"
  }
}
```

---

### GET /api/{CollectionName}
List entities with optional filtering, sorting, pagination, and joins.

**Query Parameters**:
- `filter` (string): JSON string for WHERE clause
  ```json
  {"price": {"$gt": 100}, "status": "active"}
  ```
- `sort` (string): JSON array for ORDER BY
  ```json
  [["createdAt", "DESC"], ["name", "ASC"]]
  ```
- `group` (string): GROUP BY field name
- `join` (string): JSON object for INCLUDE associations
  ```json
  {"include": {"association": "category"}}
  ```
- `offset` (number): Pagination offset
- `limit` (number): Pagination limit (max 100)
- `isCount` (boolean): Return count instead of records

**Response** (200 OK):
```json
{
  "success": true,
  "status": 200,
  "data": [
    {
      "id": "uuid1",
      "field1": "value1",
      ...
    },
    {
      "id": "uuid2",
      "field1": "value2",
      ...
    }
  ]
}
```

**Response with count** (200 OK):
```json
{
  "success": true,
  "status": 200,
  "data": 42
}
```

---

### GET /api/{CollectionName}/:id
Read a single entity by ID.

**Path Parameters**:
- `id` (string): Entity identifier

**Query Parameters**:
- `join` (string): JSON object for INCLUDE associations

**Response** (200 OK):
```json
{
  "success": true,
  "status": 200,
  "data": {
    "id": "uuid",
    "field1": "value1",
    "field2": "value2",
    "createdAt": "2025-10-12T00:00:00.000Z",
    "updatedAt": "2025-10-12T00:00:00.000Z"
  }
}
```

**Response** (404 Not Found):
```json
{
  "success": false,
  "status": 404,
  "error": "Entity not found"
}
```

---

### PUT /api/{CollectionName}/:id
Update an entity by ID.

**Path Parameters**:
- `id` (string): Entity identifier

**Request**:
```json
{
  "field1": "new_value1",
  "field2": "new_value2"
}
```

**Response** (200 OK):
```json
{
  "success": true,
  "status": 200,
  "data": {
    "id": "uuid",
    "field1": "new_value1",
    "field2": "new_value2",
    "updatedAt": "2025-10-12T00:10:00.000Z"
  }
}
```

---

### DELETE /api/{CollectionName}/:id
Delete an entity by ID.

**Path Parameters**:
- `id` (string): Entity identifier

**Response** (200 OK):
```json
{
  "success": true,
  "status": 200,
  "data": null
}
```

## Contract: Authentication Endpoints

When `AuthSystem` is initialized, the following auth endpoints are available:

### POST /api/auth/register
Register a new user.

**Request**:
```json
{
  "username": "john_doe",
  "email": "john@example.com",
  "password": "SecurePass123!",
  "firstName": "John",
  "lastName": "Doe",
  "userRoleId": "uuid-optional"
}
```

**Response** (201 Created):
```json
{
  "success": true,
  "user": {
    "id": "uuid",
    "username": "john_doe",
    "email": "john@example.com",
    "firstName": "John",
    "lastName": "Doe"
  }
}
```

---

### POST /api/auth/login
Login with username/email and password.

**Request**:
```json
{
  "login": "john_doe",
  "password": "SecurePass123!"
}
```

**Response** (200 OK):
```json
{
  "success": true,
  "user": {
    "id": "uuid",
    "username": "john_doe",
    "email": "john@example.com"
  },
  "accessToken": "token_string",
  "refreshToken": "refresh_token_string",
  "expiresAt": "2025-10-13T00:00:00.000Z"
}
```

---

### POST /api/auth/logout
Logout current session (requires authentication).

**Headers**:
```
Authorization: Bearer {accessToken}
```

**Response** (200 OK):
```json
{
  "success": true,
  "message": "Logged out successfully"
}
```

---

### POST /api/auth/refresh
Refresh access token.

**Request**:
```json
{
  "refreshToken": "refresh_token_string"
}
```

**Response** (200 OK):
```json
{
  "success": true,
  "accessToken": "new_token_string",
  "refreshToken": "new_refresh_token_string",
  "expiresAt": "2025-10-13T00:00:00.000Z"
}
```

---

### GET /api/auth/verify
Verify token is valid (requires authentication).

**Headers**:
```
Authorization: Bearer {accessToken}
```

**Response** (200 OK):
```json
{
  "success": true,
  "message": "Token is valid",
  "user": {
    "id": "uuid",
    "username": "john_doe",
    "email": "john@example.com",
    "role": "user"
  }
}
```

---

### GET /api/auth/me
Get current user information (requires authentication).

**Headers**:
```
Authorization: Bearer {accessToken}
```

**Response** (200 OK):
```json
{
  "success": true,
  "user": {
    "id": "uuid",
    "username": "john_doe",
    "email": "john@example.com",
    "firstName": "John",
    "lastName": "Doe",
    "userRole": {
      "id": "role-uuid",
      "code": "user",
      "level": 1
    }
  }
}
```

## Contract: Error Responses

All endpoints follow a consistent error response format:

```json
{
  "success": false,
  "status": 400,
  "error": "Error message describing what went wrong"
}
```

**Common Status Codes**:
- `400`: Bad Request (invalid input)
- `401`: Unauthorized (missing or invalid token)
- `403`: Forbidden (insufficient permissions)
- `404`: Not Found (entity doesn't exist)
- `500`: Internal Server Error

## Contract Versioning

**Version**: 0.1.0 (Initial version)

**Breaking Changes**: Any change that requires application code modification will increment major version.

**Non-Breaking Changes**: 
- Adding new optional parameters
- Adding new endpoints
- Adding new exports
- Bug fixes

**Deprecation Policy**: Deprecated features will be marked in documentation and emit warnings for one major version before removal.
